# Conditional Poisson on simulated panel data

This case validates the `cpoisson` (conditional Poisson / fixed-effects Poisson)
estimator on simulated panel counts with group-specific fixed effects.

## Dataset

- **Name:** `simulated`
- **Source:** generated by `data/gen.py`
- **Licence:** n/a
- **Size:** 1,600 observations (400 entities × 4 periods), with some all-zero
  groups dropped by the conditional likelihood.

## Reference implementation

- **Python:** exact conditional Poisson likelihood. Conditional on the group
  total `S_g`, the counts follow a multinomial with probabilities proportional
  to `exp(x * beta)`. The MLE is found by Newton's method using an analytic
  gradient and Hessian.
