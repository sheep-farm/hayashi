# Conditional logit on simulated panel data

This case validates the `clogit` (conditional / fixed-effects logit) estimator
on simulated matched groups with group-specific fixed effects.

## Dataset

- **Name:** `simulated`
- **Source:** generated by `data/gen.py`
- **Licence:** n/a
- **Size:** variable (groups without within-group variation are dropped)

## Reference implementation

- **R:** `survival::clogit(y ~ x + strata(group), data = df)`

## Compared quantities

- coefficients
- standard errors

## Tolerances

| Quantity | Tolerance | Rationale |
|---|---|---|
| coefficients | 1e-4 | Conditional logit MLE should match |
| standard_errors | 1e-4 | Same MLE covariance |
