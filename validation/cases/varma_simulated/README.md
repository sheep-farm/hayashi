# VARMA(1,1) on simulated bivariate series

This case validates the `varma` (vector ARMA) estimator on a simulated
bivariate VARMA(1,1) DGP with known AR and MA matrices.

## Dataset

- **Name:** `simulated`
- **Source:** generated by `data/gen.py`
- **Licence:** n/a
- **Size:** 500 time periods, 2 variables

## Reference implementation

- **Python:** `statsmodels.tsa.VARMAX(df[["y1", "y2"]], order=(1, 1), trend="n`).
  Coefficients are mapped into the same column-major vectorisation used by
  Hayashi (`ar0..ar5`, `ma0..ma3`); `ar0` and `ar1` are the zero intercepts.
