# spatial_durbin_simulated

Spatial Durbin model on simulated grid data.

Data generated on a 7x7 grid with rook contiguity W, rho=-0.95, beta=0.5. The Durbin model is highly collinear, so the comparison covers only the spatial autoregressive parameter at the unchanged `2e-1` tolerance. Standard errors are unavailable in these exports and excluded from qualification; this case does not qualify their inference.
