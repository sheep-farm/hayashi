# Three-stage least squares on a simple simultaneous system

This case validates the `threesl` (three-stage least squares / 3SLS) estimator
on a two-equation simultaneous system with correlated errors.

## Dataset

- **Name:** `simulated`
- **Source:** generated by `data/gen.py`
- **Licence:** n/a
- **Size:** 500 observations

## Model

```
y1 = c1 + a1*x1 + a2*y2 + u1
y2 = c2 + b1*x2 + b2*y1 + u2
```

`x1` and `x2` are exogenous; `y1` and `y2` are endogenous. Each equation
includes an intercept and is identified using the excluded exogenous variable
from the other equation as an instrument.

## Reference implementation

- **Python:** `linearmodels.system.IV3SLS`, with each equation specified as
  `dependent ~ exog + [endog ~ instruments]`.

## Compared quantities

- coefficients
- standard errors

## Tolerances

| Quantity | Tolerance | Rationale |
|---|---|---|
| coefficients | 1e-4 | 3SLS closed-form should match |
| standard_errors | 1e-4 | Same GMM/FGLS covariance |
