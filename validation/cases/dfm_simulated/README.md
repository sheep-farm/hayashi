# dfm_simulated

Dynamic factor model on simulated data.

Notes: Simulated four observed series driven by two common factors. All variables are
standardised in data/gen.py, so the quantities compared are communalities
(1 minus observation-noise/uniqueness variance). This is invariant to the
arbitrary sign/rotation of the estimated factors. Standard errors are not
available in the tidy output and are therefore set to NaN on both sides.
