# sfa_production_simulated

Stochastic frontier production validation on simulated Cobb-Douglas data.

- DGP: Cobb-Douglas production with negligible inefficiency.
- Hayashi: `sfa_production` on the generated data.
- References: `frontier::sfa` (R) and a Python stochastic-frontier MLE.
- Output: `variable,coef,std_err` CSV with frontier coefficients.
